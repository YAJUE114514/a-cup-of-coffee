# a cup of coffee

这是一个以“咖啡实验室”为主题的解谜 / 走迷宫小游戏。玩家扮演 hana，在一张格子地图里移动、捡起物品、组合材料，并通过关卡中的逻辑规则完成目标。

## 在线试玩

👉 **在线体验**：<https://YAJUE114514.github.io/a-cup-of-coffee/>

## 本地运行

项目使用 **ES Modules**，不能直接双击 `index.html` 打开（浏览器会拦截）。用以下任一方式启动本地服务器：

- **VS Code**：安装 **Live Server** 插件 → 右键 `index.html` → *Open with Live Server*
- **命令行**：在项目目录运行 `python -m http.server 8000` → 浏览器打开 `http://localhost:8000`

自带**地图编辑器**（`editor.html`），打开后在编辑器里画好关卡，可以点「测试」直接试玩自己画的关卡。

## 游戏目标

每一关的核心目标是：

- 把地图上的所有可操作物品整理为“咖啡”
- 玩家不能持有咖啡本身，必须把所有东西都变成最终成品
- 通过关卡后进入下一关，直到通关结束

游戏中的核心动作是：

- 走动：使用方向键或 WASD
- 捡起物品：走到物品所在格子并为空手时自动拾取
- 放下物品：按 F 键将手中物品放到脚下
- 合成：豆子 + 杯子 -> 咖啡
- 改写：标签类物品会把地上的物品改成对应的目标类型

## 玩法规则

### 1. 物品系统

物品分为几类：

- 基础物品：beans, cup, coffee
- 标签物品：tag_of_beans, tag_of_cup, tag_of_coffee, tag_of_tag

标签的作用是改变其他物品的类型，常用于配平关卡中的数量关系。

### 2. 合成规则

最核心的合成是：

- beans + cup = coffee

这意味着若玩家手持豆子走向杯子，或手持杯子走向豆子，就会生成一杯咖啡。

### 3. 标签规则

- tag_of_X 会把一格上的非 X 物品改写成 X
- tag_of_tag 会把普通物品转成对应的“标签物品”
- 同类型不生效：例如 tag_of_beans 不能对 beans 生效

这是一种“类型重写”机制，常被用来修正多余物品数量。

### 4. 地形规则

地图里有以下地形：

- wall：墙，不能穿过
- floor：可走地面
- plate：压力板，站上去或被物品压住时打开机关门
- door：机关门，只有在 pressure 被触发时才打开
- gate：检查门，需要手持符合要求的物品才能通过

## 控制说明

- 方向键 / WASD：移动
- R：重置当前关卡
- F：把手持物品放在当前位置
- 空格 / Enter：在过渡页中立即开始
